# Elanithi I — Responsive Portfolio

A responsive student portfolio created for the Thiranex **Advanced CSS3 & Responsive Architecture** task.

## Features

- Semantic HTML5 structure
- CSS Grid for two-dimensional layouts
- Flexbox for navigation and component alignment
- Mobile-first responsive media queries
- CSS custom properties (variables)
- Light/Dark mode using JavaScript + CSS variables
- Responsive mobile navigation
- Accessible labels and ARIA attributes
- Responsive layouts for mobile, tablet and desktop
- Interactive contact-form validation

## Files

- `index.html` — Home page
- `about.html` — About and projects page
- `contact.html` — Contact page
- `style.css` — Complete responsive styling
- `script.js` — Navigation, theme toggle and form interaction

## Technologies

HTML5 • CSS3 • JavaScript • GitHub Pages
